# Week 3 — AI API Assistant

## Overview

This week explores using a generative AI API from Python to build a question-and-answer assistant.

## Mini-projects

### [Matatu Assistant](Matatu%20Assistant/README.md)

A command-line prototype for a Thika matatu SACCO. It uses Gemini to interpret member questions and answer from sample information supplied in a system prompt.

## Shared setup

The specialization uses one virtual environment and one dependency file at the repository root. Follow the [main repository README](../README.md).

Add your Gemini key to the root `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Do not create another virtual environment or install dependencies from a week-specific requirements file.
