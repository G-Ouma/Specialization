# Automation and Productivity

This area contains practical projects that automate repetitive tasks and explore collecting information from websites.

## Projects

| Project | Description | Documentation |
|---|---|---|
| File Automation — Legal Client File Sorter | Organizes files in a target folder into categories based on file extension and records moves in a log | [File Automation README](File%20Automation/README.md) |
| Web Scraping — Jobs Monitor | Web-scraping learning project with its own scraper, dependencies, and captured CSV output | [Jobs Monitor README](Web%20Scraping/Jobs%20Monitor/README.md) |

## Shared Python setup

The projects use Python. The File Automation script uses only the Python standard library. Jobs Monitor has its own `requirements.txt`; follow its project README for installation and execution instructions.

For the repository's shared Python environment, see the [main README](../README.md).

## Skills explored

- Automating repetitive file-management tasks
- Working with file paths and extensions
- Creating directories and moving files safely
- Logging actions for traceability
- Collecting and storing information from web pages

Read each project's documentation before running it, especially when pointing an automation script at real files.
