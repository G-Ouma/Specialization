# Matatu SACCO Member Assistant

## Overview

A Python command-line prototype for answering common member questions for a fictional matatu SACCO based in Thika, Kenya. A member enters a question and Gemini generates a concise response using facts embedded in the application's system prompt.

The application does not connect to a live SACCO database or verify member identity.

## Demonstration information

The current prompt contains sample information about:

- A demonstration member account, THK-014, with an outstanding balance of KSh 3,500 as at 3 November 2026.
- A general members' meeting listed for Friday, 13 November 2026 at 10:00 a.m. at the SACCO office in Thika.
- A KSh 500 registration fee, KSh 2,000 joining fee, and KSh 1,000 monthly contribution.

**All these details are fictional demonstration data.** Do not treat them as current SACCO records or use this prototype to disclose real member financial information.

## Requirements

- Python and the repository's shared virtual environment.
- A Google Gemini API key.
- Dependencies installed from the root `requirements.txt`.

## Configuration

Add the following to the repository-root `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

The current script sets the model name directly in `main.py` (`gemini-3.5-flash-lite`).

## Run

From this project directory, with the shared environment activated:

```powershell
python main.py
```

Ask about the demonstration balance, next meeting, or membership fees. Enter `exit` or `quit` to close the assistant.

## Error handling and logging

The script handles missing API configuration, Gemini API errors, authentication failures, rate limits, service errors, and connection problems with user-facing messages. Technical errors are written to `assistant_errors.log` in the current working directory.

## Files

- `main.py` — interactive command-line application, Gemini request, and system prompt.
- `test_assistant.py` — live API checks for differently phrased questions.
- `test_gemini.py` — Gemini connectivity check.
- `assistant_errors.log` — runtime error log generated by the application.

Run the live question checks from this folder with:

```powershell
python test_assistant.py
```

The checks require a valid API key and make real Gemini requests.

## Limitations and future work

The balance, meeting, and fee details are hard-coded. There is no member authentication, database integration, administrative interface, or persistent conversation history. A real deployment would require verified data sources, secure access controls, privacy safeguards, and a human escalation process for sensitive or uncertain questions.
